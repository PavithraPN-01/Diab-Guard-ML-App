# Diabetes Prediction System

An end-to-end machine learning project that uses **Logistic Regression** to predict the onset of diabetes based on diagnostic measurements. This repository contains the full data science workflow, from exploratory data analysis (EDA) to model deployment.

## 📂 Project Structure
* `app.py`: The web application entry point.
* `Logistic_Regression_Logic.ipynb`: The core research notebook including EDA, feature engineering, and model training.
* `requirements.txt`: Comprehensive list of dependencies.
* `.gitignore`: Configured to exclude heavy model artifacts and temporary files.

## 📊 Dataset Overview
The project uses the Pima Indians Diabetes dataset, which includes features such as:
* Glucose concentration
* Blood Pressure
* Body Mass Index (BMI)
* Diabetes Pedigree Function
* Age

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Virtual environment (recommended)


## 🛠️ Setup Instructions

1. Install dependencies: `pip install -r requirements.txt`
2. Ensure `diabetes_model.pkl` and `scaler.pkl` are in the root folder.
3. Run the app: `python app.py`
