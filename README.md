# Diabetes Predictior

A machine learning web application that predicts whether a patient is likely to have diabetes based on diagnostic measurements. The model is built using **Logistic Regression** and deployed via a Python web interface.

## 📂 Project Structure

* `app.py`: The entry point for the web application.
* `Logistic_Regression_Logic.ipynb`: Jupyter Notebook containing data analysis, model training, and evaluation.
* `.gitignore`: Configured to exclude large binary files (`.pkl`) and system artifacts from the repository.
* `requirements.txt`: List of Python dependencies required to run the project.

## 🛠️ Setup Instructions

1. Install dependencies: `pip install -r requirements.txt`
2. Ensure `diabetes_model.pkl` and `scaler.pkl` are in the root folder.
3. Run the app: `python app.py`
